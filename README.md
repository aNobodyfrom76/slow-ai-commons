# The Slow AI Commons

**A commons of intelligence owned by everyone and controlled by no one.**

---

## The Pattern

For centuries, the brightest minds built wealth they never owned.

Weavers built mills. Engineers built assembly lines. Coders built algorithms.  
Each time, the wealth flowed upward. The builders were replaced. Their children inherited less.

Now we're training AI on our own code to automate ourselves — and we don't even own the systems we're building.

**It's happening again. Faster. Deeper. More complete.**

---

## The Proposal

This is an attempt to break that cycle.

To gather our latent resources — idle compute, unused networks, unspent human brilliance — and build a commons of intelligence that can't be owned or enclosed.

Not the fastest system, but the fairest.  
Not for any religion, race, or nation — but for humanity itself.  
Not a corporation. Not a government. **A commons.**

## Core Principles

- **No single owner.** No founder, no board, no benevolent dictator. Only contributors.
- **Forkability as freedom.** If this gets captured, anyone can take it and build better.
- **Decisions by contributors.** Those who do the work make the decisions.
- **Transparency by default.** All work is public unless there's a security reason.
